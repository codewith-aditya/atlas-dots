# Plugin examples

- [MCP server](mcp-server/README.md): wrap a hosted MCP server with an optional skill.
- [Hello world](hello-world/README.md): a skill without an MCP server.

Copy an example into a public GitHub repository, then follow [Build a plugin](https://atlasdots.com/docs/build-a-plugin/)
to test and submit it. Atlas Dots reads plugin files; it never runs repository code.
